# Panduan Kontribusi

Terima kasih telah tertarik untuk berkontribusi pada CB-PhoneHunter!

## Cara Berkontribusi

### 1. Fork Repository
Klik tombol \"Fork\" di halaman GitHub repository.

### 2. Clone Repository Lokal Anda
```bash
git clone https://github.com/username-anda/cb-phonehunter.git
cd cb-phonehunter
```

### 3. Buat Branch Fitur
```bash
git checkout -b fitur/fitur-baru
```

### 4. Lakukan Perubahan
- Pastikan kode mengikuti gaya koding yang ada
- Tambahkan komentar untuk kode yang kompleks
- Update dokumentasi jika diperlukan

### 5. Commit Perubahan
```bash
git commit -m "Deskripsi perubahan yang jelas"
```

### 6. Push ke Branch
```bash
git push origin fitur/fitur-baru
```

### 7. Buat Pull Request
Buka Pull Request di GitHub dengan deskripsi yang jelas tentang perubahan Anda.

## Standar Kode

- Python 3.8+
- PEP 8 compliance
- Dokumentasi inline untuk fungsi kompleks
- Error handling yang proper

## Laporan Bug

Jika menemukan bug, buat issue dengan:
- Deskripsi jelas tentang bug
- Langkah reproduksi
- Output error/traceback
- Environment (OS, Python version, etc.)

## Pertanyaan atau Saran?

Buat discussion atau issue di repository untuk pertanyaan umum.

Terima kasih!
